# HARIKASHI — مشروع جديد من الصفر

واجهة عربية متجاوبة بالأسود والذهبي، مع تسجيل دخول، سجل إنجازات يومية، ساعات دراسة، وملاحظات للمواد الثماني. يدعم المشروع قاعدة بيانات PostgreSQL عند نشره عبر Render، ويمكن تثبيته كتطبيق ويب (PWA) من المتصفح بعد نشره على HTTPS.

## الملفات
- `index.html` الواجهة.
- `main.py` خادم FastAPI وواجهات API.
- `requirements.txt` مكتبات Python.
- `render.yaml` إعداد خدمة Render وقاعدة PostgreSQL.
- `manifest.webmanifest`, `sw.js`, `icon.svg` ملفات التثبيت الأساسية كتطبيق ويب.

## النشر على Render
1. ارفع الملفات الموجودة في هذا المجلد إلى مستودع GitHub جديد أو مستودع مخصص للمشروع.
2. في Render اختر New → Blueprint واربط مستودع GitHub الذي يحتوي `render.yaml`.
3. راجع إعدادات الخدمة وقاعدة البيانات ثم أنشئهما.
4. انتظر نجاح النشر وافتح رابط الخدمة `onrender.com`.
5. أنشئ حساب اختبار باسم مستخدم من 3 أحرف أو أكثر ورمز دخول من 6 أرقام.
6. سجّل إنجازًا وملاحظة، ثم أعد تحميل الصفحة وتأكد من بقائهما.

## ملاحظات مهمة
- لا تضع كلمات مرور أو أسرار في ملفات GitHub. Render ينشئ `HARIKASHI_SECRET_KEY` من إعداد `render.yaml`.
- التخزين محليًا باستخدام SQLite متاح للتجربة فقط؛ في Render يستخدم `DATABASE_URL` قاعدة PostgreSQL.
- خطط الاستضافة المجانية قد تتضمن إيقاف الخدمة عند الخمول وحدودًا أو مدة صلاحية لقاعدة البيانات. تحقق من الشروط الحالية قبل الاعتماد طويل الأمد.
- ملف PWA لا يساوي ملف Android AAB ولا يعني أن التطبيق أصبح منشورًا في Google Play. هذه مرحلة أولى؛ بعد نجاح النشر والاختبار نجهز مسار Android والنشر.
- قبل استخدامه مع بيانات مهمة، يلزم إجراء اختبارات فعلية على الخدمة المنشورة، وتفعيل نسخ احتياطي مناسب، وإضافة ترحيلات قاعدة البيانات ومحددات لمحاولات تسجيل الدخول.
