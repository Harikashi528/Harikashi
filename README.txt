تطبيق نخبة التوجيهي
1) ارفع كل ملفات هذا المجلد على استضافة مجانية (Netlify أو GitHub Pages).
2) افتح الرابط بمتصفح كروم على الموبايل.
3) القائمة ⋮ ثم "تثبيت التطبيق" (Install app).
بياناتك بتنحفظ على جهازك، وزر "النسخ الاحتياطي" بصفحة الجدول لحفظ نسخة منها.
لتحديث التطبيق لاحقاً: ارفع الملفات الجديدة مكان القديمة ثم سكّر التطبيق وافتحه مرتين.
